# Incident system

The engine correlates event batches into one raid, spam, or possible-nuke incident with severity, actors, source event IDs, explainable signals, timestamp, status, and summary. Recommendations remain non-destructive.

The next phase persists incidents and appends an immutable timeline of detections, automated attempts, Discord results, moderator actions, notes, and resolution. Evidence collection must be incident-specific and respect guild archive settings; unavailable content is shown as unavailable rather than reconstructed.
